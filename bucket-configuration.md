
# Amazon S3 Bucket Configuration

## 1. Bucket Name
Example: malika-s3-static-portfolio-demo

Note: This is an example name, not an actual AWS bucket.

## 2. AWS Region
Choose an AWS Region close to your users.

## 3. Object Ownership
Bucket owner enforced is the recommended setting for most use cases.

## 4. Block Public Access
Keep Block Public Access enabled by default.
Only change these settings when public access is specifically required and understood.

## 5. Bucket Versioning
Versioning can be enabled to preserve and recover previous versions of objects.

## 6. Encryption
Use server-side encryption to protect stored objects.

## Conclusion
This document describes the basic configuration options for an Amazon S3 bucket. Actual bucket creation has not been performed.
