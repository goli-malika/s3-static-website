
# Amazon S3 - Basic Concepts

## 1. What is Amazon S3?
Amazon Simple Storage Service (S3) is a cloud storage service used to store and retrieve data.

## 2. S3 Buckets
A bucket is a container used to store objects in Amazon S3.

## 3. S3 Objects
An object is an individual file stored inside an S3 bucket, such as HTML, images, PDFs and videos.

## 4. S3 Permissions
Permissions control who can access and perform actions on S3 buckets and objects.

Common access control methods:
- IAM policies
- Bucket policies
- Access control lists (ACLs)
- Block Public Access settings

## 5. S3 Storage Classes
- S3 Standard: Frequently accessed data.
- S3 Intelligent-Tiering: Data with changing access patterns.
- S3 Standard-IA: Infrequently accessed data.
- S3 One Zone-IA: Infrequently accessed data stored in one Availability Zone.
- S3 Glacier Instant Retrieval: Archive data needing quick access.
- S3 Glacier Flexible Retrieval: Archive data with flexible retrieval time.
- S3 Glacier Deep Archive: Long-term archival storage.

## Conclusion
Amazon S3 provides scalable cloud storage with different access control options and storage classes.
