
# Amazon S3 - Upload and Manage Files

## 1. Upload Files
1. Open the Amazon S3 console.
2. Select an existing bucket.
3. Click Upload.
4. Add files or folders.
5. Click Upload to start the process.

## 2. Download Files
1. Open the S3 bucket.
2. Select the required object.
3. Choose Download.

## 3. Delete Files
1. Select the object.
2. Click Delete.
3. Confirm the deletion.

## 4. Organize Files
S3 uses object keys and prefixes to organize files.
Example:
- images/profile.jpg
- documents/resume.pdf
- website/index.html

## 5. Important Note
These are the documented S3 operations.
Actual file upload and management in an AWS bucket have not been performed.

## Conclusion
Amazon S3 allows users to upload, download, organize and delete stored objects.
